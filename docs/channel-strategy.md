# Стратегия канала

Статус: бриф (01.11), стратегия не написана. Решения по уровням — ADR-0007 (дополнение 01.11).

## Задача (пользователь 01.11)
- **YouTube** (канал школы) — только ролики эпизодов, по порядку номеров, раз в неделю.
- **Свой Telegram-канал** — главное место. Первая задача: **упаковать уже сделанное (эпизоды 01–14) в публикации
  для Telegram**. Вторая: стратегия на будущее: эпизоды 15+ вместе с уровнями конструктора, новые миры.

## Что уже есть по каждому эпизоду (сырьё для постов)
- ролик mp4 (01, 02; остальные после дублей голоса);
- в сценарии `docs/episodes/NN-*.md`: «Шпаргалка» / «В описание» (что осталось за кадром, оговорки tech-expert),
  «Обложка и финал», «Нарезка под Shorts (отложено)»;
- кадры перед бедой (стоп-кадры) — основа викторин «что сломается?»: `npm run shots -- --scene NN`;
- уровень конструктора по эпизоду 10 (выходит после 10).

## Вопросы для стратегии
1. Набор публикаций на эпизод: ролик, викторина до/после, шпаргалка, нарезка, закулисье — что из этого и в какой день.
2. Ритм недели и календарь выпуска 01–14 (01 уже вышел) с уровнем после 10.
3. Путь зрителя: ролик у школы → финальная карточка и описание → канал → уровень.
4. Темы 15+: какие кирпичи нужны конструктору, от частых в работе к редким; у каждой — мир и уровень.
5. Вовлечение и метрики (подписчики, прохождения, переходы).
6. Открытое из ADR-0007: название проекта, ссылка в финальной карточке, Mini App.

## Порядок работы
Новый агент `channel-strategist` (sonnet) — черновик; tech-expert сверяет темы и тексты, learning-designer — викторины.
Шаблон упаковки делаем на одном эпизоде (01 или 02), утверждаем у пользователя, потом раскатываем на остальные.
