# План: кухня 01 (`?scene=kk`) — фаза 2, шлифовка

Сюжет: набросок kk, 39 кадров, принят пользователем 11.11 («все устраивает»). Фаза 2 — по слову пользователя 11.11.
Решения пользователя: **тестов сцены не пишем** («не понимаю, зачем их здесь делать»); голос пока синтез —
дубли пользователя и mp4 только в фазе 3 по его команде.

**Готово, когда** kk — черновик: всё, кроме голоса и mp4. Закадр и тексты в кадре прошли цепочку
tech-writer → tech-expert → learning-designer; отрисовка и анимация по motion-designer; звук по sound-designer;
итоговая сверка tech-expert и мой проход по диффу; контактные листы (`npm run shots -- --scene kk --sheet`)
проверены глазами; пользователь смотрит в браузере `?scene=kk`.
