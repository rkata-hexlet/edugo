## 11.11 — поиск формата
- Пользователь: «мы не делаем окончательный ролик, ищем новый формат — сам до конца не понимаю, что хочу».
  Три наброска одного момента (трюк «убрали FOR UPDATE»), серые фигуры, `src/scenes/k1-formats/`:
  `?scene=fa` — дубли (группа, хлопушка, гэг), `fb` — как ловят обман (5 шагов), `fc` — загадка (угадай вердикт).
  Общий пульт приборов во всех трёх. Пользователь: «все не то — по сути ты повторяешь ролик»; наброски удалены.
- **Формат найден (пользователь 11.11): «вот это то, что я хочу увидеть».** Минимум конкретного сюжета. Тема —
  почему верное техническое решение не проходит проверку с первого раза: врёт не решение, а измерение. Пять классов:
  окно перехода (рестарт, завершение процесса), шум под видом сигнала, нагрузка не воспроизводит поломку, проверка
  меряет не то, модель в голове расходится со стендом. Примеры — из всех сюжетов (`incident-lab/docs/state.md`,
  «Что понял за сессию», и правила в `incident-lab/CLAUDE.md`). Сценарий v3 про late-emails устарел как основа.
- Ход: основной — один цикл (красное → почему → правка → снова), классы по ходу; второй вариант для сравнения —
  пять классов по очереди. Подробности и открытые вопросы — `incident-lab/.data/notes/videos.md`.

## 11.11 — два наброска хода нового формата
- `src/scenes/k2-measure/`: `?scene=kc` — цикл (23 кадра, пять кругов, полка заполняется по порядку встречи),
  `?scene=kk` — пять классов (29 кадров, глава = плашка, 2–3 примера, правило). Общая доска: цепочка
  «решение → прибор → вердикт» со счётчиками правок (решение 0, прибор 5), картинка примера, полка классов,
  агент и автор. Закадр синтезом; тест — правок решения 0, прибора 5, полка полная, кегли и низ кадра.
- Путь цикла собран из разных сюжетов (пул→CPU, дедлок без залпов, откаты чтения, параллельный прогон, рестарт 0,7%) —
  в закадре так и сказано. Техническую точность примеров tech-expert ещё не сверял.
- Открыто: сквозной образ (сейчас — доска с прибором), персонажи (агент и автор почти без реплик), финальная мысль.
