## 11.11 — поиск формата
- Пользователь: «мы не делаем окончательный ролик, ищем новый формат — сам до конца не понимаю, что хочу».
  Три наброска одного момента (трюк «убрали FOR UPDATE»), серые фигуры, `src/scenes/k1-formats/`:
  `?scene=fa` — дубли (группа, хлопушка, гэг), `fb` — как ловят обман (5 шагов), `fc` — загадка (угадай вердикт).
  Общий пульт приборов во всех трёх. Пользователь: «все не то — по сути ты повторяешь ролик»; наброски удалены.
- **Формат найден (пользователь 11.11): «вот это то, что я хочу увидеть».** Минимум конкретного сюжета. Тема —
  почему верное техническое решение не проходит проверку с первого раза: врёт не решение, а измерение. Пять классов:
  окно перехода (рестарт, завершение процесса), шум под видом сигнала, нагрузка не воспроизводит поломку, проверка
  меряет не то, модель в голове расходится со стендом. Примеры — из всех сюжетов (`incident-lab/docs/state.md`,
  «Что понял за сессию», и правила в `incident-lab/CLAUDE.md`). Сценарий v3 про late-emails устарел как основа.
- Ход: основной — один цикл (красное → почему → правка → снова), классы по ходу; второй вариант для сравнения —
  пять классов по очереди. Подробности и открытые вопросы — `incident-lab/.data/notes/videos.md`.

## 11.11 — разборы набросков (learning-designer, tech-expert)
Пользователь: «это то, что нужно — но ничего не понятно: что такое прибор, как он соотносится с нашей системой».
Разборы: `docs/reviews/kitchen-01-{learning-designer,tech-expert}-sketches.md`. Сходятся:
- «Прибор» — три пустых ящика без системы; единого прибора в incident-lab нет. Под ним в набросках — четыре разных
  звена: площадка, нагрузка, проверка, наши представления (модель). Нужна схема системы до любого термина.
- Нет нормы: сначала честный путь «поломка → красное → починили → зелёное», потом хук «верная починка — а красное».
- «Красное» четырёх родов, их смешали: отказ верной починке, пропуск ложной (нет в набросках), не та подсказка,
  замер опроверг нашу модель (вердикта не было).
- Выдумано или искажено: пул→CPU как красное (было опровержение разбора), 63/485 — ложная починка, дедлок «проверке
  не с чем», заголовки sed/cgroup/zeroRows, шкала рестарта. «Ни один сюжет не позеленел с первого прогона» — не подтверждено.
- Примеров 13, половина непонятна без сюжета → 5–6 понятных, каждый подсвечивает своё звено схемы.
- Цикл склеен из трёх сюжетов; настоящий единый путь — `failing-orders` 09.11, он закрывает пять классов.
- Ходы: каркас «пяти классов» + драматургия цикла внутри главы (learning-designer).

переделать с общим началом, гибрид — потом, если зайдёт.
Порядок: общее начало → цикл на failing-orders и kk с 1–2 примерами на класс → кадр ложного зелёного в обоих →
листы tech-expert и learning-designer → приёмка пользователем.

2. «Прибор» убрать: правки ложатся на звенья схемы со своими счётчиками; «решение» — 0 правок.
