# Эпизод 14 — «Фичефлаги» (рабочее название)

Тема: новая функциональность прячется в коде за флагом, включает и выключает её человек с пульта без деплоя. Механика, которую
видно на картинке: кому показывать (процент по хэшу гостя), где живёт флаг (локальная копия правил в поде, а не запрос в сервис),
и главное — **флаг откатывает код, а не данные**: выключили флаг — старая ветка встретила данные нового формата и отменила брони.
Мир — **сервис бронирования отеля** (гость, рамка «Сервис бронирования» с подами, Postgres-слон). Ветка от `episode/13-keyset`,
выпуск после 13. Эпизод понятен без прошлых.
Разборы: `docs/reviews/14-tech-expert-arc.md` (техническая основа, «не обещаем», данные кульминации, факты Knight Capital),
`docs/reviews/14-scriptwriter-arc.md` (хук, сквозные нити, **раскадровка 27 + итог 5 + outro с закадром дословно** — источник текста MVP).

Статус: **MVP принят (30.10, 33 кадра, `?scene=14`), фаза 2 — шлифовка по `docs/plan-14-polish.md`.**

## Решения
- 30.10 — тема и мир (пользователь): feature flags, мир отеля, от ветки 13.
- 30.10 — структура по tech-expert: три кейса «проценты → где живёт флаг → откат». Наивный «сервис флагов лёг → лежит оплата»
  возможен только при запросе в сервис на каждый вызов — показываем его как наивную попытку кейса 2; лечит локальная копия правил
  (не «кэш»), дефолт — для холодного старта; цена — поды до 30 с расходятся → решение принимается один раз и едет с бронью.
- 30.10 — данные кульминации: **вариант A** (мой выбор, пользователь может поменять на приёмке): новая оплата пишет
  `payment: at_hotel`; старая ветка обработчика брони (в том же бинарнике, за флагом) считает незнакомое «не оплачено» и отменяет
  бронь. Вариант B (`total` число → объект, `cannot unmarshal`) отброшен: падение 500 менее понятно зрителю, чем отменённая бронь.
- Решение кейса 3 — фразой «флагом включаем запись нового формата, а не чтение»; expand/contract — тремя состояниями строки брони,
  без DDL. Contract убирает старую ветку и флаг, а не поле.
- Хук — кульминация тизером («выключили — стало хуже»); Knight Capital — рифмой в итоге («у нас выключили флаг — данные остались,
  у них откатили код — флаг остался»), факты только из разбора tech-expert (приказ SEC 34-70694).
- Слова: «пульт/ползунок»; не звучат «рубильник» (circuit breaker в 10), «флажок» (`pending` в 12), «кэш».

## Картинка
- Пульт флага — вне рамки подов, на столе дежурного: ползунок процентов 0…99 с чертой порога + кнопка вкл/выкл; рука с кружкой.
- Новая оплата — вторая кнопка на телефоне гостя «Оплатить при заселении»; в поде — развилка `if`.
- Бакеты — бирки на гостях `07 · 24 · 58 · 91`; подсвечены те, кто ниже черты.
- Сервис флагов — будка справа вверху; копия правил — карточка-блокнот в поде, кольцо обновления «30 с».
- Дефолт — подсвеченный третий аргумент в `flags.Bool(ctx, "pay_at_hotel", false, …)`.
- Кейс 3 — под раскладывает карточки броней по ящикам «оплачено / ждём / иначе»; `at_hotel` падает в «иначе» → зачёркнута.
  Код и SQL зрителю читать не нужно.
- Строка брони — `H-8120 · 12 400 ₽ · payment: …`.

## Арка (раскадровка — `docs/reviews/14-scriptwriter-arc.md`)
**Знакомство и норма (1–5):** хук-тизер (гость у стойки, бронь отменена) → мир → флаг (Feature flag; деплой ≠ включение) → норма:
выключили за секунду (Kill switch; дежурный «Выключаю — и всё как было.») → оговорка: флаг защищает только код за `if`.

**Кейс 1 из 3 «Кому показывать новую оплату?» (6–11):** монетка на запрос — гость прыгает, бронь рвётся по шагам →
`hash(флаг:гость) % 100` — бакет (Percentage rollout, stickiness голосом) → 10 → 30 %, прежние остаются → соль = имя флага.

**Кейс 2 из 3 «Где должен жить флаг?» (12–19):** спрашиваем сервис на каждый запрос → он лёг, оплата стоит → копия правил в поде
(Local evaluation) → снова лёг — не заметили → холодный старт: дефолт и его ловушка (Safe default) → цена: поды до 30 с расходятся →
решение едет с бронью.

**Кейс 3 из 3 «Выключили флаг — а как было не стало» (20–27):** брони `at_hotel` в базе → старая ветка не знает значения →
выключили: брони отменяются (рифма хука) → флаг откатывает код, не данные → expand: все читают новое (Expand · contract) → флаг
включает запись, выключение безопасно → contract и цена (три деплоя, ниже «умеет читать» не откатить).

**Итог (28–32):** повтор образов + Knight Capital (Flag debt). **Outro:** «Выключатель не откатывает данные: сначала научи читать,
потом включай писать.»
