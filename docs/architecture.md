# Архитектура

## Зоны
| зона | каталог | что там | как часто меняется |
|---|---|---|---|
| каркас | `src/engine/` | контракт сцены, плеер (play/pause/шаг/скорость), примитивы отрисовки | редко |
| прикладной код | `src/scenes/NN-name/` | эпизоды: `sim.ts` (модель), `script.ts` (акты), `view.ts` (отрисовка) | постоянно |
| composition root | `src/main.ts` | реестр сцен + сборка плеера | при добавлении сцены |

## Сущности
- `Scene<S>` (`engine/contract.ts`) — просчитанная последовательность `Step<S>` + `render(state)`.
  Плеер ничего не знает о содержимом сцены, сцена ничего не знает о плеере.
- `sim.ts` — чистая модель предметной области (поды, строки таблицы, транзакции, блокировки).
  Детерминирована, покрывается тестами: «без блокировки — дубль есть, со SKIP LOCKED — нет».
- `script.ts` — сценарий: какие действия каких участников в каком порядке (акты эпизода).
- `view.ts` — рисует состояние в SVG. Анимация — интерполяция между соседними состояниями.

## Порядок сборки (main.ts)
1. Импорт сцен → реестр. 2. Выбор сцены (из URL). 3. Создание плеера с этой сценой. 4. Монтирование в DOM.

## Граф зависимостей
```
main.ts ──► engine/* ──► engine/contract.ts
   └──────► scenes/* ──► engine/contract.ts (+ engine/draw при необходимости)
```
Сцены не импортируют друг друга. Циклов нет.
