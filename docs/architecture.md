# Архитектура

## Зоны
| зона | каталог | что там | как часто меняется |
|---|---|---|---|
| каркас | `src/engine/` | контракт сцены, плеер (play/pause/шаг/скорость), примитивы отрисовки | редко |
| прикладной код | `src/scenes/NN-name/` | эпизоды: `sim.ts` (модель), `script.ts` (акты), `view.ts` (отрисовка) | постоянно |
| composition root | `src/main.ts` | реестр сцен + сборка плеера | при добавлении сцены |

## Сущности
- `Scene<S>` (`engine/contract.ts`) — просчитанная последовательность `Step<S>` (акт, подпись,
  состояние) + `render(pen, state)`. Плеер ничего не знает о содержимом сцены, сцена — о плеере.
- `Pen` (`engine/contract.ts`, реализация `engine/pen.ts`) — узкий порт отрисовки: `rect/text/line/path/group`
  по ключам. Тот же ключ в следующем кадре — тот же SVG-узел, поэтому переезд группы анимируется
  CSS-транзишеном сам. Сцены рисуют только через `Pen`, DOM не трогают.
- `Sound` (`engine/contract.ts`, реализация `engine/audio.ts` на Web Audio) — узкий порт звука:
  `tone`, `noise`, `babble(voice, text)`. Процедурный синтез, без файлов; AudioContext — по первому
  жесту пользователя. Mute — в localStorage (удобство зрителя).
- `Narrator` (`engine/narrator.ts`) — закадровый голос через Web Speech API: говорит по предложениям
  (онлайн-голоса Chrome обрывают длинные фразы), страховочный таймер на случай, если синтез не
  сообщит о конце; без голоса или в mute — выжидает расчётное время. Словарь произношения сцены
  (`Scene.pronounce`) применяется только к речи — экран и субтитр не меняются. `VOICE_DELAY_MS` —
  пауза перед голосом, её же использует тест хронометража.
- Контракт кадра: `Step.narration` (текст диктора);
  `Pen.path`, `Pen.group(…, attrs)` — для дуг и приглушения (фокус).
- Плеер (`engine/player.ts`) — кадры, подпись, ◀ ▶ ▶▶, скорость, список актов, ←/→/пробел,
  номер кадра в `#step=N` (ссылка на конкретный кадр для обсуждения), 🔊/M, CC/C — субтитры
  диктора (по умолчанию выключены). Автопроигрывание листает, когда истёк `hold` и диктор договорил;
  бормотание персонажей под диктором тише; после голоса — пауза `POST_VOICE_MS`. Звучит только
  шаг вперёд и старт воспроизведения; перемотка обрывает звук.
- `sim.ts` — чистая модель предметной области (поды, строки таблицы, транзакции, блокировки,
  журнал внешних эффектов — `letters`). Детерминирована, покрывается тестами. Предикаты
  `duplicates` / `stuck` — по ним тест сверяет табло попыток (`World.board`) с моделью.
- `script.ts` — сценарий: `Director.shot(подпись, действия, {verdict})` применяет операции модели и
  снимает кадр (`structuredClone` состояния). Реплики/SQL/титры живут один кадр; глава (номер кейса)
  и табло попыток живут в `Director` и переживают «свежий стол» (`scene` с новым миром).
- `World.events` — журнал событий кадра (замок, коммит, 0 строк, письмо, дубль, пропуск…). Пишут
  операции модели (`sim.ts`) и глаголы сценария; `Director.shot` очищает его в начале кадра.
- `sound.ts` — озвучка кадра по журналу событий (карта sound-designer) + голоса реплик.
- `view.ts` — рисует состояние через `Pen`. Поды неподвижны; стрелки (смотрит / держит / ждёт /
  пропустил / отправил) строятся только из состояния кадра.
- `sim.test.ts` — модель (семантика Postgres) + «сценарий не врёт» (итог каждого акта);
  `sound.test.ts` — журнал событий ключевых кадров + озвучка всех кадров через фейк `Sound`.

## Порядок сборки (main.ts)
1. Импорт сцен → реестр. 2. Выбор сцены (`?scene=01`). 3. `mountPlayer(host, scene)` — плеер сам
создаёт SVG и `SvgPen`.

## Граф зависимостей
```
main.ts ──► engine/player ──► engine/pen ──► engine/contract
   └──────► scenes/NN/index ──► script ──► sim
                         ├────► view ──► sim, script(clock)
                         └────► sound ──► sim, engine/audio(syllables)
scenes/* ──► engine/contract (только типы)
```
Сцены не импортируют друг друга. Циклов нет.
