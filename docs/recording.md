# Запись эпизода в mp4

Два пути. Оба берут кадры и звуки из той же сцены, что и плеер.

## 1. Офлайн-рендер — `npm run render` (без экрана, детерминированно)
```
npm run dev                       # в соседнем терминале (http://localhost:5173)
npm run render                    # → dist/episode-01.mp4 (+ dist/episode-01.wav — звуки событий)
npm run render -- --from 60 --to 90 --out /tmp/cut.mp4   # кусок для проверки
```
- headless Chrome (`/usr/bin/google-chrome`, другой — `--chrome` или `CHROME=`) открывает
  `?capture&render`, скрипт перематывает шкалу записи кадр за кадром (`window.__edugo.seek(t)`):
  CSS-анимации и переходы ставятся на паузу в нужной точке, так что движение в ролике то же, что в плеере.
- Шкала: заставка 2.5 с → кадры (время кадра = дольше из `hold` и голоса диктора по расчётному темпу
  2.5 слова/с) → финальная карточка 4 с (`engine/timeline.ts`).
- Звук — `OfflineAudioContext` той же страницы по той же карте звуков (`sound.ts`), громкость
  подтянута `loudnorm`. Видео и звук идут от одной шкалы — синхронны по построению.
- **Голоса диктора нет**: Web Speech не пишется в файл. Вместо него в кадре субтитры диктора.
- Скорость ~17 кадров/с на 1920×1080 → полный эпизод (~6.5 мин) рендерится ~12 мин.

## 2. Живая запись с голосом (нужен разблокированный экран)
Голос — сетевой «Google русский» из Chrome; его звук идёт мимо вкладки, поэтому писать надо звук системы.
1. Открыть `http://localhost:5173/?capture` во весь экран (F11): нет панели и курсора, заставка с названием.
2. Включить запись экрана со звуком системы: OBS Studio («Захват экрана (PipeWire)» +
   «Захват выходного аудио (PulseAudio)»), разрешение 1920×1080.
3. Кликнуть по заставке — ролик пойдёт сам (клик нужен браузеру, чтобы разрешить звук и голос).
4. Конец — финальная карточка; заголовок вкладки получает « · конец». Остановить запись.
5. Обрезать начало до клика: `ffmpeg -ss <сек> -i raw.mkv -c:v libx264 -crf 20 -c:a aac out.mp4`.

Синхронность голоса и картинки в живой записи держит плеер: кадр листается, когда истекло его время
и диктор договорил, голос — через 0.5 с после смены кадра, когда движение уже закончилось.
