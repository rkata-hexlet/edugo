# ADR-0006: картинка кадра в такт фразе закадра — ОТМЕНЕНО 30.10

**Статус: отменено, код убран** (revert `2e27bb1`). См. «Отмена» в конце.

## Контекст
Кадр — одно состояние сцены, а голос читает его 10–20 секунд. learning-designer на эпизоде 14 просит шесть
мест, где картинка меняется по ходу фразы: тизер «ВКЛ → ВЫКЛ → зачёркивание», штамп «через полгода», монетка на
стрелках, формула хэша, подсветка ящиков по очереди, плашка Flag debt на последней фразе (принцип
синхронности Mayer: картинка — в момент слова). Резать кадры на мелкие — рвёт голос: дубль привязан к тексту
кадра. Плеер уже знает, когда начинается кусок закадра (`onPhrase`, по нему идёт субтитр). Решение
пользователя 30.10: доработать движок, а не резать кадры.

## Решение
- `Scene.render(pen, state, phrase)` — номер куска закадра (`phrases(narration)`), который читает диктор. Сцена
  рисует по нему то, что должно появиться на слове; сцене без такта параметр не нужен.
- Плеер: шаг вперёд рисует кусок 0, `onPhrase(i)` перерисовывает кадр по куску i тем же `Pen` (ключи те же —
  новое появляется, лишнее гаснет). Кадр без голоса (перемотка, ссылка, суфлёр) — последний кусок, полная картинка.
- Рендер mp4 и снимки: кусок по времени — `phraseAt` (`timeline.ts`, тот же расклад `phraseStarts` по длине
  дубля, что и субтитр); эффекты нового куска останавливаются от его начала. `npm run shots -- --phrases` снимает
  кадр по кускам (`NN-K.png`), плеер — `?capture&phrase=K`.

## Последствия
- Выпущенные эпизоды не изменились: параметр они не берут; снимки 01 и 02 до и после совпали побитово.
- Время куска у дубля — расчётное, растянутое на длину дубля, а не настоящая пауза в голосе: слово и картинка
  могут разойтись на доли секунды. Точнее — разметка дубля по фразам при записи, если понадобится.
- Звук по-прежнему по кадру (`World.events`): звук на фразу движок не умеет; понадобится — тот же номер куска в `sound`.

## Отмена (30.10)
- Голос — дубли пользователя одним куском на кадр; где в дубле начинается фраза, движок не знает, только расчёт по длине
  текста. На длинных кадрах (итог, 15 кусков) картинка уезжала бы от слова на секунду-две — ровно там, где такт нужен.
  Точность дала бы только разметка пауз в дубле — ещё один слой движка ради одного эпизода.
- Из шести пунктов learning-designer пять делаются статичной картинкой кадра (монетка, формула хэша, штамп, ящики без
  опережающего красного, плашка термина); такт нужен только тизеру, а тизер, показывающий финал сразу, — обычный приём серии.
- Решение пользователя 30.10: «убирай движок, делай пять пунктов статично». Эпизоды 01–13 обходились кадром = одна картинка.
- Вернуться, если понадобится: сначала метки фраз в дубле (паузы), потом `render(…, phrase)`.
