# ADR-0003: запись в mp4 — офлайн-рендер кадров + живая запись для голоса

> Голос и живая запись заменены ADR-0004 (дубли живого диктора в офлайн-рендере).

## Контекст
Выдача эпизода — веб-плеер и mp4 (решение пользователя), голос — Web Speech (как есть). Голос в
Chrome — сетевой «Google русский»: его звук идёт мимо страницы (не попадает ни в захват вкладки, ни в
Web Audio), записать его можно только звуком системы и только с живого экрана. Автоматическая запись
экрана на машине недоступна без пользователя (Wayland, блокировка сессии), а локального синтеза речи
нет. Ставить другой синтезатор — значит сменить голос, это решение пользователя.

## Решение
- **Офлайн-рендер** (`scripts/render.mjs`, `?capture&render`): headless Chrome + `puppeteer-core`,
  перемотка шкалы записи с остановкой CSS-анимаций в нужной точке, звуки событий из
  `OfflineAudioContext` по той же карте, склейка ffmpeg. Голос заменяют субтитры диктора в кадре.
- **Живая запись** (`?capture`): кадр без панели и курсора, заставка → клик → автопроигрывание →
  финальная карточка и сигнал в заголовке вкладки; пишет пользователь (OBS со звуком системы).
- Шкала времени кадров — общий модуль `engine/timeline.ts` (плеер и рендер считают одинаково).

## Последствия
- mp4 без голоса собирается одной командой и воспроизводимо; его можно смотреть с субтитрами.
- mp4 с голосом — ручная запись по `docs/recording.md`; когда появится живой диктор или локальный TTS,
  голос добавится дорожкой в офлайн-рендер (шкала уже есть: начало каждого кадра и пауза перед голосом).
- Временный `fresh`-набор анимаций в рендере: эффекты прошлого кадра доводятся до конца (`finish`), иначе
  перемотка нового кадра откатила бы их.
