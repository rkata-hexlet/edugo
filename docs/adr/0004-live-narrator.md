# ADR-0004: голос — дубли живого диктора, запись суфлёром в плеере

## Контекст
Голос диктора был синтезом Web Speech (ADR-0003): в файл он не пишется, поэтому mp4 выходил без
голоса, а ролик с голосом — только ручной записью экрана через OBS. 21.10 пользователь решил озвучивать
сам, с минимумом действий со своей стороны: без экспорта, разметки и именования файлов (Audacity с
метками отклонён как «не очень удобно»).

## Решение
- **Дубль на текст кадра**, ключ — хэш текста (`engine/takes.ts`, FNV-1a). Правка закадра сама делает
  дубль устаревшим, сдвиг номеров кадров ему не мешает. Финальная фраза (`Scene.meta.outro`) — тоже дубль.
- **Суфлёр `?record`** (`engine/recorder.ts`, только `npm run dev`): кадр + текст крупно; пробел —
  сохранить дубль и сразу писать следующий, Backspace — заново, Esc — пауза. Начинает с первого кадра
  без дубля. Запись — MediaRecorder (webm/opus), шумодав браузера включён, автоусиление выключено.
- **Обработка на dev-сервере** (`vite.config.ts` → `scripts/voice.mjs`, ffmpeg): срез щелчков клавиши
  по краям, тишины, гула и шума, громкость к −16 LUFS → `public/voice/<сцена>/<ключ>.ogg` и справочник
  длительностей `takes.json`. Сырые записи — `voice/<сцена>/` (в репо): смена фильтров — `npm run voice`
  без перезаписи голоса.
- **Плеер и рендер**: `Narrator` играет дубль, без дубля — синтез (как раньше). Шкала (`timeline`) берёт
  длину дубля, субтитры раскладываются по ней пропорционально. Рендер кладёт дубли в ту же
  `OfflineAudioContext`-дорожку, что и звуки событий, — голос и картинка синхронны по построению.

## Последствия
- mp4 с голосом — одной командой `npm run render`; живая запись экрана (OBS) больше не нужна.
- Кадр длится по реальному голосу, а не по расчётному темпу: ролик меняет длину после записи.
- Правка текста после записи требует перезаписи устаревших кадров (суфлёр сам начнёт с них).
- Субтитр по пропорции может разойтись с голосом на долю секунды при долгой паузе внутри кадра;
  при нужде — отметки кусков при записи или поиск пауз в дубле.
- Сырые дубли старых версий текста остаются в `voice/` (на случай отката текста); обработанные без
  сырых `npm run voice` удаляет.
