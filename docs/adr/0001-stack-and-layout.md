# ADR-0001: стек и раскладка

## Контекст
Проверяем гипотезу: короткие анимированные сцены помогают запомнить темы бэкенда. Нужны быстрые
итерации (MVP ролика → обсуждение → доработка) и в перспективе два режима: ролик и интерактив
(«сломай сам»). Видео-движки (Motion Canvas, Remotion) хороши для роликов, но интерактив в них вторичен.

## Решение
- TypeScript + Vite, без UI-фреймворка, рендер в SVG; тесты — Vitest.
- Сцена = детерминированная симуляция (список состояний) + функция отрисовки состояния.
  Плеер общий для всех сцен.
- Раскладка: `src/engine/` (каркас) / `src/scenes/NN-*/` (эпизоды) / `src/main.ts` (composition root).

## Последствия
- Логику сцены можно тестировать без браузера — сцена «не врёт» про БД.
- Интерактив позже = подменить сценарий действиями пользователя поверх той же симуляции.
- Видео не из коробки: запись через браузер (Playwright/MediaRecorder) — отдельная задача, когда понадобится.
- Нет готовых твинов/таймлайнов — пишем минимальную интерполяцию сами; при росте сложности — подключить GSAP.
