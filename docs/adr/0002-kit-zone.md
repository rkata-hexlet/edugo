# ADR-0002: серийный набор `src/kit/` и расширение Pen

## Контекст
Эпизод 01 доводим до финала (`docs/plan-01-polish.md`). Разбор motion-designer: кадр «выглядит как
отладка» — эмодзи вместо иконок, мелкие кегли, цвет без ролей, z-order случайный (новый узел
вставлялся в конец SVG), исчезновение без перехода. Персонажи (поды, слон, Почта), виджеты (таблица,
замок, талон, табло, SQL-окно), тема и словарь движений нужны **всем эпизодам серии**, а не одному.
Держать их в `scenes/01-*` — копировать во второй эпизод; держать в `engine/` — смешать каркас
(плеер, порты) с визуальным языком, который меняется чаще.

## Решение
- Новая зона **`src/kit/`** между каркасом и эпизодами: `theme` (палитра, кегли, шрифты),
  `icons`, `characters`, `widgets`, `motion.css`. Импорты: `scenes/* → kit → engine/contract`;
  kit не знает ни плеера, ни моделей эпизодов (принимает простые параметры: цвет, эмоция, текст).
  Каталог заводится на этапе 3, с первым содержимым.
- Чего не хватало в порте `Pen`, добавлено в `engine/` (без этого kit не нарисовать):
  - **слои** `layer("back" | "main" | "front" | "top", …)`; внутри слоя порядок наложения =
    порядок рисования (узлы переставляются `moveBefore`, чтобы не сбить CSS-переходы);
  - **transform группы** (`rotate`, `scale`, `origin`) — для pop, тряски, штампа;
  - **анимация ухода**: элемент, которого нет в новом кадре, гаснет `LEAVE_MS`; при перемотке —
    `frame(draw, { instant: true })`, исчезает сразу;
  - **`Span[]`** в `text` — подсветка SQL и акценты в реплике;
  - **`measure`** — рамка по тексту вместо оценки «7.2 px на символ».
- `Scene.meta` (номер, название, подзаголовок, финальная фраза) — для обложки и финальной карточки
  плеера (этап 2).

## Последствия
- Визуал второго эпизода собирается из kit; эпизод держит только своё (модель, сценарий, раскладку).
- `Pen` по-прежнему без DOM для сцен: эффекты — только из состояния кадра и `World.events`.
- Порядок рисования в `view.ts` стал значимым: что нарисовано позже, то выше (раньше решал кадр,
  в котором узел появился впервые).
- Тесты `SvgPen` — в happy-dom (`src/engine/pen.test.ts`); `measure` там оценочный, настоящий
  размер текста — только в браузере после `document.fonts.ready`.
