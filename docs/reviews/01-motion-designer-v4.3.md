По коду, без запуска. Статус пунктов — в `docs/plan-01-polish.md`.

## Диагноз «выглядит как отладка»
Кегли 12–15 px на 1280×720; эмодзи вместо иконок; цвет без ролей (оранжевый замка ≈ под B); белый
фон и коробки; приглушение без перехода; стрелки-`line` не анимируются; плеер — страница с `<select>`
и «кадр N/M»; z-order в `SvgPen` случайный (`appendChild` в конец — узел из позднего кадра поверх).

## Визуальный язык серии
- **Цвет = кто, форма = что, красный/зелёный = итог.** Ожидание — пунктир цвета пода + песочные часы.
- **Тёмный фон** (`#0E1325`→`#161D38`), surface `#1B2342`, surface-2 `#242E55`, line `#34406E`,
  ink `#EEF1FF`, muted `#8F9AC4`; A `#4DA3FF`, B `#FFB84D`, C `#B98CFF`; ok `#3DDC97`, error `#FF5C6C`;
  Postgres `#7F93BD`, Почта `#5CC8D6`.
- **Шрифты** Inter + JetBrains Mono через `@fontsource/*` (офлайн, для записи); ждать `document.fonts.ready`.
  Кегли: плашка 56, реплика 24, SQL/таблица 20, минимум 18. Не влезает — убрать, а не уменьшить.
- Сетка: таблица x 40–610, SQL под ней; поды x 660–830; Почта x 940–1240; табло под подами/Почтой.
- Скругления 16/12/пилюли; обводка 1.5/3; плоские тени (смещённый rect), без фильтров.

## Персонажи и предметы
- **Под-«боб»**: тело rx 34, брюшко, антенна-индикатор, ножки, бейдж-буква, глаза; **зрачки смотрят на
  цель** (из `seen/carrying/waiting`). Эмоции из состояния: idle (моргание, дыхание), работает,
  ждёт (песочные часы, постукивание), выиграл (pop + кольцо), проиграл (тряска + ✕), завис
  (десатурация, z z z, без моргания), упал (глитч → призрак), проснулся («!»), говорит.
  **Купол процесса** вокруг пода — мьютекс внутри, замок БД снаружи.
- **Слон-Postgres** (очки, бабочка, штамп для COMMIT), **Почта** — ящик с лицом, журнал-карточка.
- Таблица-ведомость, строки-карточки с кромкой цвета владельца, чипы статуса, сегментный счётчик.
- Замок (дужка открывается/защёлкивается), талон-билетик цвета пода (перехват — билет в строке
  меняет цвет, у B остаётся свой), полоса срока-капсула (красное после пересечения дедлайна),
  SQL — окно редактора с подсветкой, табло — светодиоды с иконками критериев.
- Ярлык-пилюля, полноэкранная плашка главы, штамп перемотки (grayscale + scanlines + ⟲).

## Словарь движений
Все изменения кадра — в первые 450 мс, голос с 500 мс; одновременно ≤ 2 движущихся объектов; loops
только у «проживаемых» состояний. Переезд 600 мс `cubic-bezier(.4,0,.2,1)`; pop 280 мс back-out;
фокус opacity 350 мс до .38 + saturate; стрелки рисуются dashoffset 350 мс; штамп 220 мс; тряска 360 мс;
отскок 420 мс; полёт письма 700 мс; смена стола — уезд/въезд строк каскадом.
**Эффекты — из `World.events`** (как звук): lock/relock, commit, one, zero, wait, skip, send, duplicate,
replay, wake, crash, ticket, page. Разовый эффект = новый ключ узла. Перемотка — класс `no-anim`.

## Расширения Pen
P1 transform-атрибуты group (scale/rotate/origin) — мало; P2 слои `pen.layer` (чинит z-order) — мало-средне;
P3 анимация ухода (`leaving`, `frame(draw,{instant})`) — средне; P4 `text` со `Span[]` (подсветка SQL) — мало;
P5 `measure` — мало. Круги, defs, фильтры — не нужны.

## Плеер
Тёмная страница, 16:9 по viewport; подпись и CC — оверлей внутри кадра (попадает в запись); панель-оверлей
(▶, прогресс сегментами по актам, скорость, CC, звук, полный экран), прячется; dev-режим (`?dev`/D) для
`<select>` и номера кадра; обложка (`Scene.meta`) и финальная карточка; `?capture` для записи.

## Архитектура
Новая зона **`src/kit/`** — серийный набор (theme, motion.css, icons, characters, widgets);
`scenes/* → kit → engine/contract`. Нужны ADR и правка architecture.md.
