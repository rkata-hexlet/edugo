# Версия tech-writer (18.10) — к tech-expert
Отличия от версии scriptwriter (остальное без правок):

- 32b «Без транзакции выходит дёшево, но после падения задача висит навсегда. Значит, нужен способ, который справится с обоими случаями.»

- 44 «А ключ идемпотентности делает повторное письмо безвредным: получатель узнаёт его и просто возвращает прежний ответ. Только вместе эти три защиты справляются с зависшим подом.»
