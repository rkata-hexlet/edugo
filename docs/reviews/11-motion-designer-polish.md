## 3. Предметы и персонажи (спецификации)

1. **Карточка WAL (запись)** — rect 44×52, rx 6, stroke 2; обычная: fill surface2, stroke line; гостевая: fill warn, stroke warn + «ушко» вверху (path-треугольник 8 px, как закладка). Внутри крошечная полоска-«строка таблицы» (rect 24×4 цвета bg 0.5, 2 штуки) — отличает от пустого слота. Над каждой пятой карточкой LSN моно 16 px **не ставить** (кегль ≥18): LSN только у золотой и у бегунков. Слоты пустые (ещё не записанные) — штриховой контур.
   - Появление: `fx-pop` 250 мс, летит от primary по ленте до своего слота (translate, ease-out cubic 500 мс).
   - Если у вас `tape:c{lsn}` ключ — тот же узел, переезд при сдвиге окна анимируется сам.
2. **Бегунок реплики** — «флажок»: вертикальная линия 3 px от верха ленты до y+18 (как сейчас) плюс **кружок-головка 14 px** с цифрой реплики (шрифт 16 жирный белый на заливке цвета реплики) на верхней точке — вне ленты, над ней (y = cardY − 18). Тогда подписи не нужны, а цвет реплики = цвет бегунка = цвет рамки плашки (реплика 1 — postgres-голубой, реплика 2 — лиловый). Подписи «отстаёт N с» убрать полностью (кроме кадра 8, где объясняем лаг, и то диапазон-полоса). Переезд — CSS-transition `transform 700ms cubic-bezier(.4,0,.2,1)` на группе `tape:runN` (ключ стабильный) — уже должно работать через Pen по ключу.
   - Лежит: бегунок серый, без головки-кружка, вместо него «×» и штрих.
3. **Реплика как персонаж** — слон `elephant`, scale 1.0. Состояния: *работает* (глаза смотрят на ленту, при чтении — talking), *отстаёт* (небольшой «хвост» — три точки-«эхо» слева от плашки, `fx-blink` 1.4 с — «догоняю»), *лежит* (красная плашка, закрытые глаза, «z» плавает вверх 2 с loop только в этих кадрах), *синхронная* (двойной контур + сплошная толстая связь с primary). **[kit]** состояния `asleep`, `catching-up` для `elephant`.
4. **Содержимое реплики** вместо «броней гостя: N» — мини-таблица 3 строки × 24 px в плашке; строка-бронь (рамка warn) появляется `fx-slide` сверху, когда бегунок проходит соответствующую карточку (в такт ленте, не по таймеру). Нет брони — «пусто» курсивом, как в «Мои брони» у гостя: единый образ «строка таблицы» (так серия 10 → 11). **[kit]** `rowChip` (строка таблицы 230×28, уже собран руками внутри гостя и реплики — вынести).
5. **Песочные часы COMMIT** — на primary-плашке, справа-сверху, 36 px, `hourglass` + кольцо пульса warn; подпись под ней «COMMIT ждёт» в пузыре Postgres уже есть («Записал. Жду реплику.») — часы дублируют, оставить только часы и покачивание. Над подом-A тоже убрать мелкую копию (24 px, на кадрах 21/29 это точка).
6. **Лента: диапазон лага** — rect под лентой от бегунка до конца, h 8, rx 4, fill warn 0.6 (если лаг<2 с — тусклая, >2 с — error); подпись по центру «3 с»/«5 с» моно 18. **[kit]** `lagBar` — пригодится для эпизода про лаг/очереди.
7. **Талон (LSN-билет)** — см. 22. Зубчатый край: path с 6 полукруглыми вырезами слева/справа, fill warn, text моно «0/3A2F208» 20 px тёмный. Заметьте: цвет билета = цвет золотой карточки.
8. **Часы** (`12:01:02`) — моно 22 px, слева сверху; ок, но при приближении события (3 с, 5 с) — часы тикают: цифры `fx-pulse` на смене секунды (150 мс), чтобы «время идёт» чувствовалось.

## 4. Движение в такт голосу — словарь

| Событие | Движение | Длит./easing |
|---|---|---|
| Появление объекта серии | `fx-pop` (scale .92→1, opacity 0→1) | 300 мс, ease-out |
| Появление ленты | слоты проявляются слева направо с задержкой 25 мс на слот | ≈ 400 мс |
| Новая запись | карточка вылетает из primary и скользит в слот | 500 мс cubic-bezier(.2,.7,.2,1) |
| Бегунок догоняет | transform по оси X | 700 мс cubic-bezier(.4,0,.2,1) |
| Чтение/запись (стрелка) | `fx-draw` | 400 мс, последовательно, пауза 200 |
| Ожидание (COMMIT, лаг) | часы `fx-sway` ±8°, только пока ждём | 1,2 с loop |
| Ошибка (реплика легла, ✗) | `fx-shake` 350 мс + красный пульс | один раз |
| Успех (✓) | зелёная галочка `fx-pop` + кратко подсветка рамки ok | 250 мс |
| Смена главы | затемнение 0.88 + текст `fx-slide` | 450 мс |

Привязка к `phrases`: в кадрах 5, 13–15, 22–24, итог — строить состояние кадра по фразам, а не целиком в начале. Каждая фраза = один новый объект или один сдвиг фокуса; не больше одного нового объекта на фразу. Циклические анимации (sway, z-z-z) только на объекте, о котором сейчас говорят, — иначе конкурируют с голосом.

## 7. Порядок работ (выигрыш/объём)
1. **Сетка и масштаб** (§1: сузить гостя, поднять реплики и ленту, табло/толпа на всю ширину нижнего яруса) — самый большой визуальный сдвиг, ≈ константы + пара позиций.
2. **Бегунки-флажки без подписей «отстаёт»** + цвет реплик (§3.2) и исправление лжи на кадрах 21/29.
3. **Кадр 5 по фразам** + кадр 4 «труба репликации» вместо ленты из одной карточки.
4. **Талон LSN и проверка по ленте** (22–24) — главный смысловой образ второго кейса.
5. **Итог без «пустоты»**: три образа + табло (26–30).
6. **Табло**: ряды по фразам, лампы крупнее, иконки.
7. **Реплики: таблица вместо счётчика, состояния слона.**
8. Мелочи: титры глав, пилюли терминов на фикс. позицию, `fx-sway` часов, пульс часов.

Готово, когда: на любом кадре нет более одного «главного» акцента, нижний ярус не пуст при y<655, подписей «отстаёт N с» на лежащей реплике нет, `view.test.ts` зелёный, снимки кадров 4, 5, 8, 21, 22, 23, 26–30 пересмотрены глазами.
