# Эпизод 05 · план отрисовки (motion-designer, по v1.3, 23.10)

Вердикт: язык серии держится, его не трогаем. На MVP похоже из-за трёх вещей:
- всё мелкое: поды 64 px, середина кадра пустая;
- магазин — просто рамка с текстом;
- оверлеи режут сцену пополам.

Новых примитивов Pen не нужно.

## Предметы и персонажи (`src/kit/props.ts`, серийные)
- **Токены:** `mug`, `skin`, `awning2`.
- **Поды ×1.4**, `POD = {x:620}`, `POD_Y = {A:160, B:330}`. Магазин `{x:996, y:118, w:248, h:350}`.
- **Под:**
  - ждёт — `fx-breathe` (цикл);
  - проиграл — `fx-droop`;
  - по желанию чип прочитанного числа у пода: он держит 1, пока в строке уже 0.
- **Строка:** полоска цвета автора, бейдж-кружок пода вместо «от пода A»; старые версии .45.
- **Замок:** своя отрисовка с дужкой, анимации `fx-lock` и `fx-unlock`.
- **Магазин:**
  - навес с зубцами;
  - полка с кружкой (корпус, ручка, пар), пилюля «осталось 1»;
  - аватары покупателей (голова, плечи цвета пода), кнопка «Купить»;
  - призрачная кружка, полёт кружки к покупателю на `ok`.
- **Заказ:** билетик с перфорацией, «лишний» — красный штамп −6°.
- **Слон:**
  - ×1.4, хобот толще;
  - зрачки следят за событием;
  - на `fail`/`zero` брови хмурые;
  - на 40001 «стоп».

## Движение (только по `World.events`, ≤ 0,45 с)
- **В `motion.css` добавить:** `fx-lock`, `fx-unlock`, `fx-flash`, `fx-march` (пунктир ожидания), `fx-spin`,
  `fx-breathe`, `fx-droop`, `.mv.fast` (.4 с). Транзишн для `stroke-dasharray`.
- **Привязка к событиям:**
  - read — стрелка и вспышка конца строки;
  - write — новая версия въезжает сверху, старые сдвигаются, замок «щёлк»;
  - wait — `fx-march` и `fx-breathe`;
  - commit — `fx-unlock`, вспышка зелёным, пунктир B становится сплошным;
  - check — `fx-pop` или `fx-shake`;
  - ok — кружка летит к покупателю;
  - fail — jolt, вспышка красным, «стоп» слона;
  - retry — `fx-spin`;
  - оверлей — скрим `fx-fade`, панель `fx-rise`.
