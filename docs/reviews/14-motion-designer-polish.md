## 1. Что в `kit/` не хватает (предметы серии)
Не новые примитивы `Pen`, а виджеты kit + 3 класса в `motion.css`:
1. **`dial`** (kit/widgets.ts) — пульт целиком: ползунок с ручкой (`circle` r=11, `ink`, обводка `bg`), метки «0» и «99», порог. Нужен и в эпизодах про лимиты и canary.
2. **`lane`** — полоса бакетов 0…99 с точками-гостями (см. п. 3); переиспользуется в A/B-тестах.
3. **`clock`** — кольцо-часы пода: `path` дуги с `pathLength:1` и `stroke-dasharray`; остаток = `untilRefresh/30`.
4. CSS (kit/motion.css), нужны потому что транзишен в движке есть только у `transform` группы (`player.css` `.mv`):
   - `.tw` — `transition: width .6s ease-in-out` для заливки ползунка (на rect `width` из CSS анимируется в Chrome);
   - `.fx-sweep` — in-frame анимация кольца часов: `stroke-dashoffset` от `--from` к `--to` за `--dur`; значения кладёт `view.ts` из `untilRefresh`, модель не трогается;
   - `.fx-ping` — стрелка рисуется (`fx-draw` 0.35 с), держится 0.9 с и гаснет (opacity→0, `forwards`); для «пульт сказал — поды услышали».

## 2. Находки по убыванию важности

### F1. Пузыри подов закрывают гостя и вылезают за кадр (кадры 14, 15, 17, 18, 23)
Причина: `bubble(... x: POD_X-2, tail:"right")` — пузырь растёт влево, на кадре 17 «Какой сервис? Не слышал.» и 23 «Незнакомое — не оплачено.» обрезаны по левому краю (x<0), 14/15 накрывают голову гостя.
Правка в `render` (top-слой): пузырь пода — **внутри рамки сервиса, поверх ряда копии правил этого пода**, с хвостом влево:
`bubble(pen,"pod:say",text,{ x: POD_X+66, y: POD_Y[by]+2, tail:"left", attrs:{class:"fx-pop"} })`.
Пока говорит под, его плашка `pod:${id}:rule` и `:card` уходят в `opacity: 0` (рисовать не нужно — фильтр в `drawService`: `w.podSay?.by === id`), строка лога/часов (y+60) остаётся видимой. Ширина: «Старая? Давно не видел.» ≈ 250 px → от x=378 до ≈630 — вылезает на 10 px за рамку 296…600 и в зазор перед пультом. Поэтому вместе с F8 расширить SERVICE до w=330 (CONSOLE/TWIN/BOOTH x:620→650, w 300→270; DB не двигать). Если не хочется двигать сетку — оставить x и сократить хвост: пузырь допускает вылезти на 20 px в зазор 600–620, не больше. Появление `fx-pop` 0.28 с — как есть, в момент слова; гость при реплике пода затемняется (`fade(w,id)` уже есть).
В кадре 23: реплика пода A при непонятном значении — а карточек в режиме direct нет, так что место свободно; та же координата работает.

### F2. Стрелки пульта → поды висят во всех кадрах direct (3–6, 22, 25, 26, 27, 29 и др.)
Три пунктирные стрелки из центра пульта накладываются друг на друга и на гостя, несут «пульт связан с подами» постоянно — это постоянный индикатор, шум в каждом кадре.
Правка `drawArrows`: ветку `mode==="direct"` заменить на:
- постоянно — ничего (поды и пульт уже в одной сцене; рамка сервиса — достаточный «контур»);
- на событие `toggle` (и `slide` при смене процента) — три стрелки к подам с `class: "fx-ping"`, ключи `arr:${id}:flag`, задержка по подам 0 / 0.08 / 0.16 с (`style animation-delay`), цвет `COLOR.ok` при включении, `COLOR.muted` при выключении. Точка входа: левый край пульта `CONSOLE.x`, y = середина плашки, а не `CONSOLE.y+80` — чтобы линии не шли через заголовок «Пульт».
- у упавшего пода стрелка — до края рамки и там обрывается (штрих + `cross` 18 px), как сейчас, но тоже только на `toggle`.
Вердикт для голоса: стрелка нужна, когда звучит «флаг включили»; остальное время смотрим на гостя и под.

## 3. Словарь движений эпизода (длительности, easing)
Все — из `motion.css`, новое помечено *.
| событие | движение | время | easing |
|---|---|---|---|
| появление пода/гостя на реплике | `fx-pop` | 0.28 с | spring (как есть) |
| переезд (ползунок, ручка, талоны, поды) | `.mv` transform | 0.6 с | ease-in-out |
| заливка ползунка | `.tw`* width | 0.6 с | ease-in-out |
| рычаг вкл/выкл | translate ручки | 0.25 с | ease-out |
| «пульт сказал» (стрелки к подам) | `fx-ping`* | 0.35 draw + 0.9 hold + 0.3 fade | `0.4,0,0.2,1` |
| ожидание сервиса | `hourglass` (`fx-breathe` 1.6 с) | цикл | ease-in-out |
| падение сервиса | `fx-jolt` 0.32 с + крест `fx-pop` | | |
| ошибка в логе | `fx-fade d2` | 0.35 с | |
| расхождение (крэк) | `fx-pop d2` на `!` | | |
| успех (бронь записана) | `fx-rise` на строку | 0.4 с | |
| отмена брони | `fx-draw` зачёркивание | 0.35 с | |
| часы копии | `fx-sweep`* | 3 с в кадре | linear |
| талон падает в ящик | `fx-hop` | 0.42 с | |
Правило: за кадр — **один** акцент на каждой фразе закадра; второй не раньше +0.5 с (классы `d2`…`d4`).
