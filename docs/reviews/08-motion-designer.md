## Обязательно
1. Колонки `idempotency_keys`: `locked_until` обрезан рамкой, `processing—` слипается. Без lease — status 84, response 214;
   с lease — response 206, lease 330, в response только код `200` (текст ответа виден на телефоне).
2. Рот лица банка задевает журнал при двойном списании: лицо выше (y+12), ряды с y+52 шагом 36, плашка 32.
3. Стрелки под→банк режут подпись «Pod B», стрелка мёртвого пода — плашку «OOM Killer»: подпись и плашку — под тело
   пода по центру; стрелки мёртвого пода — следы, приглушённые, без ключа.
4. Затемнение кадров кода и «Попыток» начинается с y=116 — торчит верх рамки банка: скрим на весь кадр.
5. Балансировщик (кадры 2, 7): узел с вилкой между телефоном и подами, ветки к подам; в кадре 7 — ветка на B.
6. Кадр 3: пометки «сначала банк» / «потом запись» появляются разом, голос называет их по очереди — нарезать на шаги.
7. Срок `locked_until` в момент захвата: заголовок колонки и ячейка подсвечены, часы пульсируют.
8. Вставка 01: приглушить таблицу очереди, слона и часы — говорим о Почте.
