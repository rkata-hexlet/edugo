# Кухня 01, сцена kk — motion-designer, этап 4 (отрисовка и движение)

Основа: контактные листы `out/shots/kk/sheet-*.png` (41 кадр), `view.ts`, `script.ts`, `src/kit/theme.ts`, `src/kit/motion.css`,
разбор learning-designer (`kitchen-01-learning-designer-kk.md`, п. 8–10 и «Что требует отрисовки»). Сюжет и тексты не трогаю.
Нумерация — по листам (`NN.png`); «кадр 37 итог» из запроса на листах = кадр 38 (кольца «измерение»), кадр 37 — правило «меряем скорость».

Общее: схема читается, иерархия «активное/приглушённое» работает, цвета по ролям соблюдены (красный/зелёный = итог, жёлтый = внимание,
postgres-голубой = база). Недоделки — в трёх местах: (1) картинки-примеры в нижней панели — текст в карточках или график вместо образа;
(2) раскладка: мёртвые зоны и разнобой осей; (3) уровень затемнения и мелкие наезды.

Словарь движения, который достаточно иметь (всё уже есть в `src/kit/motion.css`, кроме двух строк — они помечены «+»):
| что | класс | длительность / easing |
|---|---|---|
| появление предмета, значка, пилюли | `fx-pop` | 0.28 s, overshoot (есть) |
| появление панели, подписи | `fx-rise` | 0.4 s, ease-out (есть) |
| смена фона/затемнения, кольца | `fx-fade` | 0.35 s (есть) |
| линия графика | `fx-draw` | 0.35 s (есть; не вешать на штриховые пути — он перебивает `stroke-dasharray`) |
| + рост полосы во времени («идёт время») | `fx-grow`: `scaleX 0→1`, `transform-box: fill-box; transform-origin: left center` | 1.6 s, linear |
| + падение «разом» (залп) | `fx-drop`: `translate 0 -36px → 0`, opacity 0→1 | 0.25 s, `cubic-bezier(.5,0,1,.6)`, без отскока |
| + сдвиг по времени внутри кадра | `fx-d1/d2/d3`: `animation-delay` 0.4 / 0.8 / 1.2 s | — |
Ошибка = красный `fx-pop` + (для дедлока) один удар кольца; ожидание = рост полосы `fx-grow` (и ничего больше). Дрожания, пульсации,
бегущих точек не делаем — они конкурируют с голосом.

## 1. Затемнение незатронутого (DIM)

**Решение: 0.32, но локально в сцене, и только для контента; навигацию (полка причин, круг задачи) держать на 0.55.**
- Не 15–20 %: при 0.32 `muted`-текст (#8f9ac4) даёт ≈ (55,62,88) на фоне (14,19,37) — ещё различим как «серая карта», при 0.18 уже
  сливается с фоном, а 18-px подписи превращаются в артефакт. Согласен с learning-designer.
- Не менять `DIM` в `src/kit/theme.ts`: он общий для серии, выпущенные эпизоды перерисуются (правило «общий код вливается, только
  если выпущенные эпизоды не изменились»). В `view.ts` ввести `const DIM_KK = 0.32; const DIM_NAV = 0.55;` и в `lit()` брать
  `DIM_NAV` для `shelf` и `loop` (там дим-чипы остаются читаемыми: это «дорога эпизода», зритель сверяется с ней).
- Усиление вместо дальнейшего затемнения: активным блокам, о которых говорит голос, добавить рамку `stroke: COLOR.line → COLOR.muted` (2 px)
  — разница «горит/спит» растёт без падения читаемости. Уже сделано у `panel` в фокусе, проверить после пересъёмки.
- Кадры для оценки после правки: 3, 12, 33, 36, 38 (где горит сразу несколько блоков).

## 4. Общие дефекты отрисовки

4.1 **Раскладка и мёртвые зоны.** Схема занимает 1068×420 слева-сверху; PIC начинается с x=420 (центр 840), поэтому в кадрах с картинкой
слева-снизу пустота 400×180, а правый край кажется «убежавшим» к колонке круга. → `PIC = { x: 16, y: 470, w: 1068, h: 176 }` — совпадает
со сеткой площадки (16…1084), картинки получают ширину; внутренние координаты — от центра `W/2`. Заодно `moral` (x=140, w=1000) и
`tips` (x=140, w=1000) центровать по площадке (x=26, w=1048) или оставить по центру кадра — главное, не смешивать две оси.
4.2 **Дыра справа от «графиков» (x 826…1084, y 56…226).** Видна в каждом кадре; в кадрах 32–34 «очередь» к тому же мало места
(текст «хвост 30 тыс.» касается нижней границы панели). → растянуть графики до x=570…1064 (w=494): линии x 110…470, «очередь» —
рисовать хвост высотой до верха панели; метка «хвост 30 тыс.» — справа от точки пика, не снизу. Стрелка вердикта не страдает.
4.3 **Знаки подозреваемых (кадры 11–12).** «?» проверки садится на конец диагональной стрелки от виртуалки («стрелка указывает на ?»);
