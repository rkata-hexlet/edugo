# Эпизод 07 — карта звука (sound-designer, 24.10)

Словарь 05–06; новое в 07. Громкость ≤ 0,2; всё в первые 0,45 с; голос с 0,5 с.

| событие | звук |
|---|---|
| `write` | triangle 60 мс, 0,07; A 440, B 520 (как 05/06) |
| `wait` | три тика square 2000 Гц 15 мс, шаг 0,14; ждущий без замков (очередь) — тише 0,03/0,025/0,02 |
| `ring` | тик ожидания + «щёлк-щёлк» двух замков (noise 900 q4 на +0,06 и +0,12) + удар sine 120→70; не биение (биение — тихая беда 05/06) |
| `tick` | деревянный triangle 800/600/800, шаг 0,15 (кадр секунды); в развязке — один «так» 600 Гц |
| `detect` | двойной пинг sine 1568 Гц 2×40 мс |
| `fail` (40P01) | два «бзз» square 200 Гц 70 мс 0,17; стон отдан `refused` |
| `refused` | sine 523 → 392, 60/70 мс (вежливо, как «нет в наличии» 05) |
| `resume` | два пинга triangle 660 и 880, шаг 0,05 — не слайд (слайд у `retry`) |
| `retry`, `ok`, `commit`, `page`, `rewind`, `card`, `verdict` | как 05/06 |

**Развязка** — абсолютные смещения с конца: «так»/кольцо 0, детектор 0,06 (после кольца 0,10), «бзз» 0,17, отказ 0,31,
«динь» 0,41. Хвост одинаков в хуке (11) и SERIALIZABLE (15) — держит тест. В развязке молчат записи и коммит победителя,
перелистывание и красная лампа.

**Глушим:** `press`, `zero`; `wait` при `ring` (тик ожидания внутри кольца); `write`/`commit` при `retry`.
Бормотание Postgres: после кольца — тишина до голоса (кадр 9); в кадрах секунды и развязки 0,05; иначе 0,07.
Итог (×0,7): кольцо, «так», детектор, бзз, отказ, пробуждение, коммит, «динь».
