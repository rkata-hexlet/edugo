## Анимация по событиям (словарь)

| событие | что движется | класс/длительность |
|---|---|---|
| `lock` | замок падает на провод, дужка защёлкивается, провод пульсирует | `fx-pop` 0.28 + `fx-lock` 0.22 + провод `fx-flash` 0.4 |
| `unlock` | дужка поднимается, замок гаснет | `fx-unlock` 0.3 → `fx-fade` (opacity 1→0) 0.35 |
| `silent` | провод теряет цвет и переходит в пунктир | `fx-flash` 0.4 + смена штриха (CSS-переход) |
| `cut` | разрыв-метка на проводе, под получает «?» | метка `fx-pop`, «?» `fx-pop` |
| `crash` | под дёргается, ореол `error` | `fx-jolt` 0.32 + ореол `fx-pop`→`fx-fade` |
| `takeover` | строка `leader` меняет цвет, корона вырастает над новым лидером, тонкая стрелка B → строка | `fx-pop` 0.28 + `fx-draw` 0.35 |
| `cron` | будильники звенят каскадом | `fx-shake` 0.36, задержки `d1–d3` |
| `double` | красные строки журнала `×N`, лицо банка в тревоге, обе короны вспыхивают | `fx-slide` + `fx-flash` 0.4 |
| `replayed` | зелёная стрелка, галочка в строке, лицо `relieved` | `fx-draw` + `fx-pop` |
| `renew` | строка `leader` `fx-pop`, полоса срока снова во всю ширину | 0.28 + CSS-переход ширины 0.4 |
| `tick` | пульс часов | `fx-pulse` 0.4 (уже есть) |

Постоянные циклы только у ожидания (`fx-march` на пунктире `atBank`); молчащее соединение не анимировать. Все движения начинаются в первые 0.45 с кадра, при перемотке отсутствуют.

## Что вынести в kit

- **`crown(pen, key, {x, y, scale?, color?, stale?, attrs?})` в `kit/props.ts`.** Форма: путь с тремя зубцами и жемчужинами (3 круга r 3.5 на концах), основание — rect rx 3 высотой 6. `stale: true` — opacity 0.4 и красная перечёркивающая линия (`fx-draw`). Нужна эпизодам про лидера, а также про выбор мастера БД и шардинг.
- **`wire(pen, key, {from, to, color, state: "live" | "silent" | "cut", lock?})` в `kit/props.ts` (или `widgets.ts`).** Объединяет `drawConns`: линию, пунктир для silent, разрыв-метку для cut и бирку замка с номером. Провод с замком нужен будущим эпизодам (транзакции, изоляция: замок на строке/соединении).
- **`lock` расширить:** параметр `scale` и `tag` (текст рядом, бирка с подложкой). Сейчас размер зашит константами 22×24.
- **`leaseBar(pen, key, {x, y, w, ratio, color})`** — полоса срока для строки с `lease_until`; повторится в эпизодах 08 (locked_until) и следующих. Новый примитив `Pen` не нужен: это rect.
- Ключ-плашка на стрелке (`keyTag`) — общая с 08: сейчас `iconText` с `key`; добавить подложку и использовать в обеих сценах.

Новых примитивов `Pen` не требуется. Единственное условие: `Pen.rect` должен анимировать смену `width` (CSS-переход) для полосы срока. Если не умеет — `scaleX` на группе через атрибут трансформации (проверить `pen.ts`).
