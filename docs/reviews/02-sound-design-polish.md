# Эпизод 02 — звук после нарезки (sound-designer, фаза 2, этап 5, 27.10)

Сверка `sound.ts` с 42 кадрами после нарезки и новых лиц.

## Сделано
- **DEL после COMMIT** (главная мысль эпизода): было del на 0, «пум» COMMIT на 0.1 — слышалось наоборот. Теперь DEL на
  0.25, если в кадре есть COMMIT. Держит тест (мутация `delAt = 0` его роняет).
- **«Пятый узел» тонет**: в кадре не было события `overload` — добавлено; узел Redis тонет своим «бульк» (три синуса
  520→260 Гц), а не гулом базы.
- **SET раньше ответа**: без промаха в кадре SET — на 0, ответ — на 0.15 (кадр «B кладёт sale на час»).
- **COMMIT и 404 не слипаются**: провал после COMMIT — на 0.28; после l1hit — на 0.1.
- **Скачок часов ≥ 1 мин слышен и рядом с 404** («прошло 39 минут»): свип часов, потом провал на 0.25.
- **Перемотка без шелеста страниц**: при `rewind` звук `page` не играет.

## Не взято
- Лимит «не больше трёх громких звуков на кадр» с ранжированием видов — переделка всей раскладки; после нарезки
  плотных кадров меньше. Вернуться, если на прослушивании кадр звучит кашей.
- Звук пота базы в кадре «Опять все ко мне?» — бормотание реплики уже несёт реакцию.
- Кадры без событий (окно гонки, оговорка про реплики) — тишина уместна.
