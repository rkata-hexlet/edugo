# План: эпизод 01 до финала

Источники: `docs/reviews/01-learning-designer-v4.3.md` (LD), `docs/reviews/01-motion-designer-v4.3.md` (MD).
Решения пользователя: сюжет v4.3 утверждён; выдача — веб-плеер + mp4; голос — Web Speech; 16:9;
**тёмная тема**; **`src/kit/` + расширение Pen**; **промежуточный показ** после этапа 4.

**Готово, когда** эпизод можно отдать постороннему как законченный продукт: финальный визуал и
анимация, звук, голос, mp4. Проверка — просмотр в браузере (ключевые `#step=` и ширина ≈ 390 px),
итоговые проверки learning-designer и tech-expert, тесты зелёные.

## Сквозные решения
- Синхронность голоса и картинки — **нарезкой на микрошаги** (одна фраза — одно изменение), а не
  привязкой к словам (границы слов у голосов Chrome ненадёжны). Обе роли сходятся.
- Визуальные эффекты, как и звук, — **из `World.events`** или состояния кадра, не из сравнения кадров.
- Новая зона **`src/kit/`** (серийный набор: тема, иконки, персонажи, виджеты, motion.css) — ADR.
- Тексты (новые/изменённые фразы) — порядок scriptwriter → tech-writer → tech-expert.
